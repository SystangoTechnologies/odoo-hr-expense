To configure the receipt validation behavior:

1. Go to *Expenses \> Configuration \> Settings*.
2. In the *Expenses* section, set *Receipt Validation* to one of:
   - *Not enforced*: existing submission workflow is unchanged.
   - *Warn if missing*: the employee is warned but can still submit the
     expense report.
   - *Required to submit*: the expense report cannot be submitted until a
     receipt is attached to every expense line.

This setting is company-dependent, so it can be configured differently
per company and changed at any time without any code change.
