This module helps employees and finance teams identify expense claims
that do not have a supporting receipt attachment.

When an expense report is submitted, the module checks whether every
expense line has a receipt (attachment) and, depending on a configurable
company setting, either:

-  does nothing (default, existing behavior is preserved),
-  warns the employee that some expenses have no receipt but still
   allows the submission, or
-  blocks the submission until a receipt is attached to every expense.

Configuration
=============

To configure the receipt validation behavior:

1. Go to *Expenses > Configuration > Settings*.
2. In the *Expenses* section, set *Receipt Validation* to one of:

   -  *Not enforced*: existing submission workflow is unchanged.
   -  *Warn if missing*: the employee is warned but can still submit the
      expense report.
   -  *Required to submit*: the expense report cannot be submitted until
      a receipt is attached to every expense line.

This setting is company-dependent, so it can be configured differently
per company and changed at any time without any code change.

Usage
=====

1. Create an expense line without attaching a receipt.
2. Click *Submit to Manager* on the expense report.
3. Depending on the configured mode:

   -  *Not enforced*: the report is submitted as usual.
   -  *Warn if missing*: the report is submitted and a warning
      notification lists the expenses without a receipt.
   -  *Required to submit*: an error is raised, listing the expenses
      without a receipt, and the report stays in draft until a receipt
      is attached to each one.
